笔记栏目维护指南

本站「笔记」栏目（/blog/）已支持区分 原创 / 转载 与 AI 整理 两类内容。本文说明新增的行为，以及如何用最低成本维护这个栏目。

一、这次新增了什么

用文章 frontmatter 里的一个字段 source 区分内容来源，不另开独立栏目， 全部仍归在「笔记」一栏里：

source 取值含义在「笔记」列表里
original（默认） 本人原创，或转载 / 整理自其它网站但由人工完成 默认显示，栏目名「原创与转载」
ai 由 AI 参与整理 / 生成的文章 默认不显示；勾选滑块后才并入列表

二、访客看到的效果

筛选区多了一个滑块，默认关闭：

含 AI 整理 （默认未勾选）

列表上方栏目名：原创与转载

勾选后：

含 AI 整理

列表上方栏目名变为：全部（含 AI 整理）

凡是 source: ai 的文章，在列表项与单篇页面都会出现一个 AI 整理 标记，做到明确披露。

设计意图：大多数访客只想看人工内容，所以 AI 整理的文章默认隐藏、按需开启； 「AI 整理」标记则保证一旦展示就透明披露。转载自其它网站但人工完成的内容仍属 original，无需任何特殊标记。

三、怎么低成本维护笔记栏目

维护成本极低，核心就是「写 Markdown + 填好 frontmatter」，其余交给构建。

1. 新增一篇文章

  1. 在 src/content/blog/ 下新建 <slug>.md（文件名即 URL，建议小写英文 + 连字符）。
  2. 填 frontmatter（见下方速查表）。
  3. 正文用 Markdown 写；图片加 title 就是图注，[^1] 就是注释。
  4. 本地 npm run dev 预览，确认无误后提交。

2. 什么时候写 source: ai

  • 文章由 AI 参与整理 / 生成 → 设 source: ai。会自动打「AI 整理」标记，且默认不在列表里出现。
  • 原创、或人工转载 / 整理其它网站内容 → 不写或写 source: original（默认）。

就这么一个字段的区别，没有别的开关或配置。

3. 转载其它网站的内容

直接当作普通文章添加即可（记得在正文或 description 里注明原始出处，这是转载的礼貌也是合规需要）。 因为是人工转载，source 保持默认的 original， 它会出现在默认的「原创与转载」列表里，不需要任何额外处理。

4. 校验永远不踩坑

提交前跑一次构建，frontmatter 写错（拼错、类型不对、日期非法）会立刻报错并指出是哪个文件：

npm run build

字段缺失或 updatedDate 早于 pubDate 也会在这里被拦下，不会静默上线。

另有一个不会报错、只会默默画错的坑：正文里成对的半角波浪号 ~ 会被当成删除线，作品副标题 《加奈~妹妹~》 里的「妹妹」就会被划掉。写日文作品名时用全角 ～（《加奈～妹妹～》），或把半角波浪号转义成 \~。构建后跑一次 grep -ro '<del>' dist/blog，结果应为 0。

转载外站时图片可以只写原站地址、不下载进仓库（![图注](https://原站/xx.jpg "说明")）， 这种「远程图」构建期不会报错，原站哪天删了图也发现不了——所以要多跑一步 python scripts/check_remote_images.py，它会逐张请求并报出坏链（退出码 1）。 注意远程图必须用 Markdown 写法，手写 <img> 不经过插件，挡不住防盗链。 图片很多或原文可能下架时，还是下载下来压缩更稳。

5. 想先攒草稿

设 draft: true：不生成页面、不进首页 / 列表 / RSS / sitemap，开发环境也看不到。准备好再改回 false。

四、frontmatter 字段速查

字段必填说明
title✅不能为空，渲染成 <h1>；正文别再写一级标题
description建议一句话摘要，进首页 / 列表 / RSS / 搜索
pubDate✅日期，YYYY-MM-DD
updatedDate❌不能早于 pubDate
tags❌字符串数组，显示在文章底部
draft❌默认 false
source❌original（默认）｜ ai（AI 整理）

五、也可以让 AI 帮你维护

仓库里准备了一份 agent skill（notes-maintenance），把上面的字段约定、滑块行为、 构建校验一次性告诉了智能体。下次让 AI「按本站格式写一篇并发布」，它会自动遵循这套规则， 包括正确地设置 / 不设置 source: ai。维护笔记栏目因此变成一句自然语言指令。

相关代码：src/content.config.ts（字段校验）、src/pages/blog.astro（列表与滑块）、 src/scripts/archive-filter.ts（筛选逻辑）、src/layouts/ArticleLayout.astro（单篇标记）。
