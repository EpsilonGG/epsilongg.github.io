## 这个仓库是什么

`epsilongg.github.io` 的源码：**Astro 静态个人主页 + 一条每天自动运行的日报生产线**。无前端框架、无数据库、无后端、无 CMS，部署在 GitHub Pages。

**四个站点板块**（三条手写/自动内容线 + 一条在建）：

| 板块 | 入口 | 谁产生 | 节奏 | 自动 |
| --- | --- | --- | --- | --- |
| 个人主页 | `/`、`/me/`、`/morelinks/` | 手写 JSON / TS 配置 | 不定期 | 否 |
| 笔记 | `/blog/` | 手写 Markdown | 不定期 | 否 |
| 日报（双版） | `/daily/` | X-Reader 抓取 + 本地 LLM 整理 | 每天一期 ×2 | 是 |
| 周报 | `/weekly/` | 从已发布 Galgame 日报重建 | 每周六 | 是（出稿本地、发布自动） |

真正的数据源在 `src/config/`、`src/content/blog/`、`data/daily/`、`data/weekly/`；报告只是某个时间点的快照。
